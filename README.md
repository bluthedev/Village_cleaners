# Village Cleaners — Modern Laundry & Dry Cleaning Web App

A high-converting, modern web application for **Village Cleaners**, located at 2366 Rice Boulevard, Suite D, Houston, TX 77005 (Rice Village).

## 🌟 Key Features

- **Interactive 2D Animated Washing Machine**:
  - Vector and canvas front-loading appliance with 60 FPS physics.
  - Rotating stainless steel drum with perforated texture and lifter vanes.
  - Realistic tumbling clothes (denim, oxford shirts, towels, tees).
  - Sloshing water waves and bubbling foam.
  - User controls: Gentle (350 RPM), Eco Clean (680 RPM), and Turbo (1200 RPM) extraction modes, plus Start/Pause.
- **Multi-Page Architecture**:
  - **Home**: Hero with 2D washing machine, key trust metrics, and featured services.
  - **Services**: Detailed breakdown of Eco Dry Cleaning, Wash & Fold, Master Tailoring & Alterations, Bulky Linens, and Dexter Laundromat.
  - **Pricing Estimator**: Interactive calculator with live basket subtotal and ready date estimation.
  - **Stain Lab**: Draggable Before & After stain removal comparison slider and fabric care guides.
  - **Reviews**: 4.5/5.0 Star Google Reviews showcase with 140+ verified ratings and service filters.
  - **Hours & Location**: Real-time Houston operating status clock, parking directions, and Google Maps embed.
  - **Pickup & Delivery Booking Modal**: Universal booking flow with address validation, time window picker, and confetti confirmation.
- **Authentic Brand Identity**:
  - Brand colors extracted from Rice Village identity (Deep Navy `#0F2744`, Hydro Clean Blue `#0284C7`, Gold `#F59E0B`).
  - High-contrast typography and defined sectioning throughout.

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React Icons**
- **Canvas-Confetti**

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/bluthedev/Village_cleaners.git
   cd Village_cleaners
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
